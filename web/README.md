# Штиль — веб-приложение (PWA)

Чистый JavaScript (ES-модули), без сборки и сторонних зависимостей. Тот же принцип, что и в iOS-приложении:
**профиль, фильтры и обратная связь живут только в браузере и никуда не отправляются**; сервер отдаёт всем одну и ту же ленту (`/v1/feed`, `/v1/laws`), подбор делает `js/core`.

```
js/core/      логика на устройстве (порт FilterEngine, AudienceMatcher, разбор «о себе», регионы, маркеры СВО и политики)
js/store.js   хранение (localStorage) и кэш последней ленты
js/backup.js  зашифрованная копия профиля (PBKDF2 → AES-GCM), ключ нигде не хранится
js/ics.js     напоминание о вступлении закона в силу (файл календаря)
js/ui/        экраны; данные попадают в DOM только через текстовые узлы (без innerHTML)
sw.js         сервис-воркер: оболочка работает без сети
```

## Команды
```bash
node --test web/test/            # модульные тесты (без зависимостей)
node web/dev-server.mjs          # http://localhost:8090, /v1/ проксируется на боевой API (API_ORIGIN=… чтобы сменить)
node web/e2e/smoke.mjs           # сквозной прогон на настоящем Chrome (онбординг → лента → фильтры → копия)
```
Для просмотра экранов без онбординга на localhost: `?demo=1`, тема: `&theme=sage`, шаг онбординга: `?step=about&about=…`.

## Раздача
API-контейнер раздаёт `web/` на всех адресах, где нет маршрутов API (`WEB_DIR`, заголовки безопасности и CSP в
`backend/internal/httpapi/static.go`). `infra/deploy.sh` собирает образ с `--build-context web=../web`.
Nginx должен проксировать `/` на API: один раз от root выполнить `infra/root-web.sh`.

## Что в вебе устроено иначе, чем в iOS
- **Напоминания**: локальных уведомлений в браузере нет. Вместо них — файл календаря (.ics) с напоминаниями за неделю и за день.
  Push-уведомления потребуют хранить на сервере адрес подписки (это идентификатор устройства) и не сделаны.
- **Резервная копия**: вместо Keychain — зашифрованный код/файл, который человек сохраняет сам.
- **Хранение**: браузер может стереть данные сайта; помогает установка на экран «Домой» и `navigator.storage.persist()`.
