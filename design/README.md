# Макеты «Штиль»

Живой макет: https://claude.ai/artifact/7Kb1uD4cYoFEbiXjGm5nd1

Файлы `.dc.html` — экраны макета: HTML с inline-стилями. `{{...}}` — подстановки из `renderVals()` в блоке `<script type="text/x-dc">`, `<sc-for>`/`<sc-if>` — циклы и условия. Используй их как точную спецификацию отступов, цветов и текстов.

| Onboarding | Онбординг 1 — профиль (жизненные ситуации) |

| OnbTheme | Онбординг 3 — выбор темы и расписания (живая перекраска) |
| OnbBuilding | Онбординг 4 — анимация «Собираем выпуск» |
